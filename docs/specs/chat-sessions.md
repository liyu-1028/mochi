# 聊天会话与回忆

右键角色打开“聊天回忆”，点击“新建会话”进入空白对话。第一条用户消息写入时
自动保存会话，并使用前 30 个字符作为标题。回看记录不会改变当前聊天；点击
“继续这段对话”才切换到该会话。列表标记当前会话，并显示尚未开始的空白会话。

切换会话时关闭原 WebSocket，让服务端取消正在生成的回合；清空当前界面的
流式回复、工具确认、表演队列和输入草稿，停止语音。原连接的迟到事件和历史
请求不会写入新会话。主动陪伴通过连接的 `sessionId` 参数跟随会话；未传参数
的旧客户端仍使用 `default`。

当前选择存于 `mochi.activeSessionId`，重启沿用；首次升级沿用已有 `default`
会话。聊天记录继续使用 `SessionStore` 的 SQLite 会话表，长期记忆独立保存，
新建或删除会话不会删除用户偏好与事实。

建议在换话题、任务完成或旧上下文干扰时新建会话，不按时间或固定长度强制
分割。模型每轮最多读取本会话最近 20 条历史消息，还可能按模型上下文预算
裁剪；完整历史仍可回看。超过 20 条消息的详情页显示这一说明。

回忆面板限定内容宽度，说明自动换行，长标题省略显示。会话操作保持可见，
长文本和删除确认不会撑出窗口水平滚动条。
