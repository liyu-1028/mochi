# VRMA 动作导入（2026-10-09）

公开发行版预装 Mochi 角色和六个已有 VRMA 动作：跳舞、展示全身、比 V、转圈、模特摆姿势、蹲起运动，不使用程序化肢体表演兜底。其他没有动作包的角色保持静态自然站姿；口型、眨眼、视线和表情仍由角色渲染驱动提供。

## 使用流程

1. 从 VRoid / BOOTH 等素材网站下载并解压动作，遵循作者的使用和署名要求。
2. 在「动作管理」右上角点击「导入动作」，选择 `.vrma` 文件。
3. 填写名称和素材署名，选择归为「角色内置」或「用户扩展」。
4. 选择用途：挥手、点头等用于已有交互；「自定义动作」生成独立条目，供试听或待机随机播放。
5. 如需 AI 选择该动作，绑定语义用途后勾选「允许 AI 使用所选用途」。默认关闭。
6. 在「我的动作」中预览、修改播放设置和署名，或删除后重新导入；角色内置动作可修改名称及播放设置，原始文件和署名保持不变。

用途是文件与交互的绑定，不会自动生成该动作。相同用途只能绑定一个文件；已占用的用途在导入菜单中禁用。自己的动作可删除后重新导入，角色内置用途保留给角色动作包。「自然待机（循环）」作为待机基底持续播放；没有这个文件时保持静态站姿。「待机时随机播放」只将导入的单次动作加入待机候选池。

## 实现约定

- 角色动作包来自用户本机提供的原始 VRMA：`assets/local-motions/mochi-vrm-defaults/`（忽略 Git）。PyInstaller 构建将其打包至 `mochi_server/motion/defaults/mochi-vrm/`。
- 维护者已确认本版本六个动作获准随安装包分发；原始文件不进入公开源码或作为独立下载提供，授权不等于其他用户可继续再分发素材。
- 发布前上传 `mochi-build-motions.tar.gz` 至同 tag 的 GitHub 发布草稿，CI 下载此构建输入。公开发布前先删除原始素材附件，只发布安装包。设置 `MOCHI_RELEASE_BUILD=1` 时缺少输入将中止构建。
- 本机角色默认动作复制到 `<userData>/motion-library/role-defaults/mochi-vrm/`，下次升级仍可加载；保留已有名称及播放设置。
- 打包默认条目与用户索引按 id 合并，避免旧导入记录重复；名称和调度设置可在本地覆盖，不修改包内素材。默认文件由角色包分发，新安装无需再次导入。
- 导入前验证 `VRMC_vrm_animation` 人形骨骼轨道，读取实际时长（0.1–60 秒），不接受改扩展名的普通 GLB 或 FBX。
- 上传文件逐字节保存，播放时只执行向当前 VRM 骨架的重定向与动作切换。
- `GET/POST /motions`、`PATCH/DELETE /motions/{id}` 管理索引；`GET /motion-library/{file}` 分发文件。
- 时长来自文件，元数据编辑不提供手工改时长；内置素材不允许删除或覆盖原作者署名，用户导入可编辑署名并删除。
- 动作库变更通过窗口事件、BroadcastChannel、窗口聚焦与低频同步通知桌面角色。缺少的交互动作不执行，AI 能力清单只含已导入且显式启用的语义动作。
- 内置条目有 `source=builtin` 和 `skinId=mochi-vrm`，只用于对应角色。用户导入 `source=user`，可在 VRM 角色间使用；`GET /motions?skinId=...` 同时过滤预览、桌面播放和 AI 能力。
- 动作管理使用 900×700 的独立窗口，固定预览、分组标签和一个列表滚动区；拖动旋转、滚轮缩放、重置视角与单次播放/停止均复用 VRM 驱动。窄屏改为纵向布局。

入口：`MotionsPanel.tsx`、`motionsClient.ts`；播放：`motionLoader.ts`、`driver.ts`、`VrmStage.tsx`；服务端：`motion/library.py`、`api/motion_routes.py`、`agent/registry.py`。
